# Radio Conecta 📻
**La emisora institucional del Poli en tu dispositivo Android.**

Radio Conecta es una aplicación profesional desarrollada para ofrecer una experiencia de streaming de alta fidelidad, noticias dinámicas y contenido exclusivo de la emisora.

## 🚀 Características Principales
*   **Interfaz Pro Max:** Diseño de pantalla dividida (40/60) optimizado para una navegación fluida.
*   **Sistema de Noticias:** Tarjetas interactivas con expansión animada para leer las últimas novedades musicales (Juanes, Shakira, Bad Bunny).
*   **Identidad Visual:** Tema oscuro (Deep Black) con acentos en Amarillo Oro (`#FFD600`).
*   **Secciones Dinámicas:** Fotos, Videos, Botones de acción y Página Web integrada.

## 🛠️ Tecnologías
*   **Lenguaje:** Kotlin
*   **UI:** Jetpack Compose (Modern Android UI)
*   **Arquitectura:** Clean Architecture con componentes de Material Design 3.
*   **Multimedia:** Integración proyectada con ExoPlayer para streaming en vivo.
